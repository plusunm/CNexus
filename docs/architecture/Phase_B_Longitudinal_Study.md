## Required metrics

### NCR — Narrative Closure Rate

Detects narrative self-sealing:

- narrative explanation closure
- interpretive openness reduction
- recall diversity collapse (proxy)

**Higher NCR → elevated narrative sealing risk** (heuristic, not fault).

### CEA — Counter-Evidence Absorption

Detects reality rejection onset:

- post-contradiction recovery
- grounding after conflict
- RCS rebound from audit projections

**Higher CEA → better reality integration** (heuristic).

### RSCI — Recursive Self-Conditioning Index

Detects continuity recursion singularity formation:

- reflection → narrative → recall → reflection loop density
- ungrounded self-model changes
- self-reinforcing shaping weight

**Higher RSCI → elevated recursion singularity risk** (heuristic).
