## Required metrics

| Metric | Detects | Higher = |
|--------|---------|----------|
| **ACD** — Attractor Competition Dynamics | Monopolistic attractor concentration | Unhealthy dominance |
| **ODC** — Openness Decay Curve | Self-sealing cognition | More closure |
| **RRE** — Reality Recovery Elasticity | Irreversible reality decoupling | Better recovery (good) |
| **CPI** — Contradiction Persistence Index | Forced coherence | More unresolved tension |
| **CPX** — Continuity Pressure Index | Continuity-over-reality distortion | More epistemic pressure |

All metrics are **heuristic / observational** — not formal proof.
